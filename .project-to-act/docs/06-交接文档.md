## 1. DeepSeek Harness（DSH）任务书体系

用途：驱动外部 DSH 执行者**独立**完成集成的自包含任务包。三份主文档：

1. **上传识别与 M0 落库任务书**：三种上传模式（order / master_data / directory）；
   支持 xlsx/xlsm/xls/CSV/PDF/DOCX/图片/ZIP（magic bytes 校验）；每文件独立状态禁止
   静默 continue；12+1 类制造资料分类（缺最低字段进 needs_review）；M0 canonical
   发布 dry-run 先行、须回读 entity/version/ledger/outbox；下游 Skill 顺序
   business-data-identification→m1-parser→m0→m2→m3→m4→m5→m5-lifecycle。
2. **M1-M5 编排任务书**：修 9 个流程断点（upload 只收 XLSX、模块间从初始 request
   重建事实、M4 输出未被 M5 消费、Apply Gate 只改 RunState 不调 M5 repository、
   resume 信任 body actor 等）；T0-T6 任务（分支集成与 required-capability Gate、
   新工作流、确定性 bridge、六类 snapshot、apply 接真实 lifecycle、审批身份改认证
   principal、MES 条件任务）。
3. **M1/M2 修复证据与隔离重放申请**。

核心不变式：LLM 只做路由提案不产生产值；缺数据返回 BLOCKED_INPUT 失败关闭；
候选 ≠ canonical；真实验收必须有数据库回读而非 HTTP 200；禁用「基本完成」等模糊结论。
