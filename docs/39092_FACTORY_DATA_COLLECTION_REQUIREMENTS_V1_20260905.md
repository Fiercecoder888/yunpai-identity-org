# 39092 工厂数据采集要求（V1）

版本：V1.0  
日期：2026-09-05  
适用范围：产品、工程、生产、仓库、设备、模治具、人员及计件资料的首次整理和持续更新。

## 1. 交付原则

- 一份文件只描述一种业务主题；不要把库存、人员工资和设备混在同一张表。
- 原始文件保留，不要覆盖旧版本；文件名中写明主题、日期和版本。
- 表格第一行必须是字段名，第二行开始是数据；不要合并单元格，不要用颜色代替字段值。
- 编码必须稳定、唯一、可追溯。没有编码时先申请编码，不要临时用名称代替。
- 数量、时间、金额都填写数值和单位；日期使用 `YYYY-MM-DD`，日期时间使用 `YYYY-MM-DD HH:MM:SS`。
- 空值留空；不要用 `-`、`无`、`待定` 混在同一列中。确实没有值时填写“无”并在备注说明。
- 每张表都填写“资料日期、编制人、审核人、来源系统/文件、版本号”。

## 2. 四类主资料与配套资料

本次采集分为四类主资料：

1. BOM（物料清单）
2. SOP/工艺文件（必须带 IE 标准工时）
3. 工程图（零件图、装配图、规格图、技术变更）
4. 库存表（库存现状、批次、质量状态）

生产排程还需要一组配套主数据：机器可用信息、模治具、人员工资、产品计件工资，以及产品、物料、供应商、工位和日历信息。

## 3. BOM 资料

### 3.1 BOM 主表：一行一个产品版本

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 产品编码 | 必填，稳定编码 | `P-USB-C-001` |
| 产品名称 | 必填 | `USB-C 线材` |
| 产品规格/型号 | 必填 | `USB-C 100W 2m` |
| BOM 版本 | 必填，如 A、B 或 1.0 | `A` |
| 生效日期 | 必填 | `2026-09-01` |
| 失效日期 | 可空 | `2026-12-31` |
| 计量单位 | 必填 | `PCS` |
| 状态 | 必填：草稿/生效/停用 | `生效` |
| 编制人/审核人 | 必填 | `张三/李工` |
| 来源文件 | 必填 | `BOM_P-USB-C-001_A.xlsx` |

### 3.2 BOM 明细表：一行一个物料

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 产品编码、BOM 版本 | 必填，与主表一致 | `P-USB-C-001 / A` |
| 行号 | 必填且唯一 | `10` |
| 物料编码 | 必填，不能只填物料名称 | `MAT-CABLE-002` |
| 物料名称 | 必填 | `镀锡铜线` |
| 规格型号 | 必填 | `22AWG 红色` |
| 单位 | 必填 | `M` |
| 单台用量 | 必填，正数 | `2.05` |
| 损耗率 | 没有则填 `0` | `0.025` |
| 替代料编码 | 有多个时用独立行或分号分隔 | `MAT-CABLE-003` |
| 是否采购 | 是/否 | `是` |
| 备注 | 说明特殊要求 | `需检验导通` |

### 3.3 BOM 必须同时提供

- 产品与物料编码对照表；
- 子 BOM（组件作为物料继续展开）；
- 替代料规则、损耗率和单位换算；
- 旧版本 BOM 与新版本 BOM 的生效边界；
- 如 BOM 来自 PDF/图片，必须提供清晰原件，不能只交截图。

## 4. SOP/工艺资料（带 IE 工时）

### 4.1 工艺路线主表

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 产品编码 | 必填 | `P-USB-C-001` |
| 路线编码 | 必填 | `RT-USB-C-001` |
| 路线版本 | 必填 | `A` |
| 生效日期 | 必填 | `2026-09-01` |
| 工序总数 | 必填 | `8` |
| 状态 | 草稿/生效/停用 | `生效` |

### 4.2 SOP 工序表：一行一个工序

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 产品编码、路线版本 | 必填 | `P-USB-C-001 / A` |
| 工序序号 | 必填，按执行顺序 | `30` |
| 工序编码 | 必填且稳定 | `OP-CRIMP-030` |
| 工序名称 | 必填 | `端子压接` |
| 作业说明 | 必填 | `按作业指导书压接并拉力检查` |
| 前置工序 | 无则填 `无` | `20` |
| 工位编码 | 必填 | `ST-03` |
| 机器编码 | 有机器要求时必填 | `EQ-CRIMP-02` |
| 模治具编码 | 有工装要求时必填 | `FIX-CRIMP-01` |
| IE 标准工时（分钟） | 必填，正数；不能只填“快/慢” | `0.85` |
| IE 工时口径 | 必填：单件/批次/每人 | `单件` |
| 投入人数 | 必填 | `1` |
| 产能单位 | 必填 | `PCS/小时` |
| 质量要求 | 必填 | `拉力≥80N` |
| SOP 文件/页码 | 必填 | `SOP-USB-C-A.pdf / 3` |

### 4.3 IE 工时补充表

当一个工序存在换型、首件、批次准备或多人协作时，另附 IE 明细：

`工序编码、动作名称、动作时间（秒）、次数、人员数、宽放率、标准工时（分钟）、测量日期、测量人、审核人`。

## 7. 配套主数据

### 7.1 机器可用信息

`机器编码、机器名称、设备类型、工位/工作中心、能力标签、状态、可用开始/结束时间、维护窗口、日历编码、最大/最小批量、效率、来源日期`。

机器编码必须唯一，例如 `EQ-CRIMP-02`，不能只填写“2号压接机”。

### 7.2 模具、治具和工装

`模治具编码、名称、类型、适用产品/工序、所在位置、状态、寿命上限、已使用次数、保养到期日、校验到期日、替代模治具编码`。

### 7.3 人员工资表

`人员编码、姓名（可脱敏）、岗位、班组、技能/资格、有效期、基本工资、计薪周期、标准出勤小时、加班规则、适用工厂、数据生效日期`。

工资和身份证、银行卡等敏感信息请单独加密传送，不要放在普通生产资料表中。

### 7.4 产品计件工资表

`产品编码、工序编码、计件规则版本、生效日期、计件单位、单位计件金额、多人分配规则、良品/不良品规则、加班/特殊工序系数、审核人`。

### 7.5 其他建议主数据

- 物料主数据：物料编码、名称、规格、单位、物料类别、替代料；
- 供应商主数据：供应商编码、名称、可供物料、最小采购量、交期；
- 工位/工作中心：工位编码、名称、生产单元、可执行工序、班次日历；
- 班次日历：日期、班次、开始/结束时间、休息、停机/维护、冻结窗口。

## 8. 文件命名和提交清单

推荐命名：`主题_对象编码_版本_资料日期.扩展名`，例如：

```text
BOM_P-USB-C-001_A_20260905.xlsx
SOP_P-USB-C-001_RT-A_20260905.xlsx
DWG_DWG-USB-C-001_B_20260905.pdf
INVENTORY_WH-01_20260905.xlsx
EQUIPMENT_FACTORY-A_20260905.xlsx
TOOLING_FACTORY-A_20260905.xlsx
WORKER_RATE_FACTORY-A_20260905.xlsx
PIECE_RATE_P-USB-C-001_A_20260905.xlsx
```

每批资料同时提供：资料清单、编制人、审核人、资料日期、版本说明和联系人。
