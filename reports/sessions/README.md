# Session 实时报告目录

每个 session 创建一个独立文件：`<session-id>.md`。文件名必须与 claim 中的 `session_id` 一致。报告是过程记录，不是事后总结；每完成一个有效工作节点就追加一条记录。

## 模板

```markdown
# Session <session-id>

状态：进行中
负责人：
分支：
基线 commit：
范围：
认领路径：
开始时间：

## 当前工作

- 目标：
- 正在修改：
- 下一步：

## 时间线

### YYYY-MM-DD HH:mm

- 计划修改：
- 实际修改：
- 文件：
- 验证：命令、退出状态和摘要
- 风险/阻塞：
- 证据：

## 交接

- 最终 commit：未完成
- 未完成事项：
- 接手人：
```

## 查看约定

其他 session 只能读取报告来了解进度；如需改变对方认领范围，先通过交接记录和新的 claim 明确转移。
